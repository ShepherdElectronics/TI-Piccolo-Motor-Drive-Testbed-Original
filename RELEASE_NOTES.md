# Release Notes - v2.6

## Major change

This release replaces the prior engineering-source package with a **documentation-only black-box release**.

### Included
- Two customer-facing FRDs using the established controlled-document DOCX template.
- Functional requirements, interface categories, verification methods, acceptance criteria, limitations, and high-level capability descriptions.

### Removed from the public package
- All Simulink models.
- All MATLAB, C/C++, PowerShell, and other source code.
- Custom ADC source and generated firmware artifacts.
- Setup, deployment, commissioning, and station instructions.
- Raw and processed datasets and detailed efficiency plots.
- Schematics, BOMs, pinouts, connector maps, wiring diagrams, and manufacturing information.
- Detailed CAN identifiers, payloads, signal mappings, tuning values, and calibration constants.
- Internal development history and university/lab materials.

The intent is to demonstrate engineering scope while publishing no implementation IP.


### v2.6
- Added curated, metadata-stripped hardware photographs as non-sensitive public evidence.
- Embedded selected hardware photographs in the platform FRD.
- Continued to exclude readable Simulink screenshots, editable models, source code, setup instructions, and implementation details.
